# Muse Markdown parser fork

Copied from `github.com/wheregrassdreams/mygo/ui/markdown/parser` at
`v0.8.3-muse.2`. Muse keeps this package local so large single-line image
documents can bypass the parser's redundant line-count scan while preserving
its block and inline semantics. Keep the copy aligned with upstream parser
fixes and review changes here when updating the MyGo dependency.
