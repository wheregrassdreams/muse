# 编辑交互方案（草案）

状态：基础功能已实现（2026-11-09）；不改变源码为唯一状态、字节偏移光标和撤销模型。

## 行内公式

浏览时保留原子对象；明确编辑后，该公式临时成为可逐字符寻址的源码。
单击公式进入编辑，光标依据点击侧落在公式内容开头或结尾；从相邻正文按方向键进入公式时展开并进入内容，而非始终整段跨过。选区跨越公式时继续允许整对象选择。
编辑状态独立记录源码范围，不借选区表达。范围随替换映射，离开公式收起；公式输入不完整、暂时解析失败时仍保留编辑状态。

编辑中的公式旁显示只读 overlay：优先在公式下方，空间不足翻到上方，并限制在编辑区内。它不参与正文排版、不抢焦点、不改变光标和滚动位置。滚动时跟随锚点，锚点离开可视区时隐藏。
复用 mdoc 公式渲染与缓存，仅渲染当前公式，随 UI 帧更新；目前同步渲染，不引入异步过期结果。无效公式显示简短“公式未完成”，若保留上次成功结果必须标记为旧预览。IME 组合期间不抢候选窗，组合提交后更新。
Esc 先关闭预览，保留源码编辑；离开后重新进入恢复预览。后续模态模式中 Esc 优先完成模式退出并关闭预览，不要求按两次。

## 标题标记

标题的 # 和分隔空格是实际源码，应纳入合法光标位置、点击命中和选区；目前的灰色标记不能只是绘制装饰。
光标进入前缀时显示完整源码前缀，可逐字符修改；离开后继续按标题投影。标题降级成正文时偏移、选区与撤销保持一致。需覆盖 #、多级标题、空标题、中文、Home/左右键和鼠标命中。

## Helix / Vim

提供三种可选模式：默认、Helix、Vim；默认保持现有输入方式。模式由编辑器处理，设置由 nativeui 保存。状态栏明确显示模式和未完成按键序列。

共享底座：动作（移动、选择、替换、撤销）→ 编辑事务；键位解析器只产生命令，不直接改源码。输入法仅在 Insert 接收文本；Normal/Select/Visual 的字符命令需要避免 KeyDown 与 InputText 重复执行。Cmd 系统快捷键和应用快捷键保留优先级，弹窗打开时先由弹窗消费输入。

两种语义分别实现：

| 模式 | 首期范围 | 后续范围 |
|---|---|---|
| Helix | Normal/Insert/Select；hjkl、w/b/e、v、i/a、d/c/y/p、u、Esc；选择后操作 | 多选区、搜索扩展、对象选择、寄存器 |
| Vim | Normal/Insert/Visual；hjkl、w/b/e、i/a/o、v/V、dd/cc/yy、dw/cw、p、u、Esc；操作符待决和次数 | 文本对象、寄存器、点重复、宏、命令行 |

首期明确是基础键位集，不宣称完整兼容。两套模式不得仅以同一张快捷键表换名字：Helix 是选择优先，Vim 需要操作符待决状态。未实现的命令不得悄悄按普通文本插入。
模态移动按源码字符/单词定义；需要访问隐藏 Markdown 的命令应先展开目标构造，复用合法偏移与源码映射。不能让视觉原子对象阻断文本对象、词移动和修改。

## 验收范围

1. 先修复标题前缀和公式进入编辑规则；方向键与鼠标结果一致，源码不因展开变化。
2. 加行内公式 overlay；测试输入不完整、IME、快速输入、滚动、主题、长公式，以及不移动光标/页面。
3. 抽取共享命令层，接设置与模式提示；默认模式回归全部通过。
4. Helix 基础集，再实现 Vim 操作符与次数；用真实编辑序列验证结果、选区和撤销。

公式渲染不得混入全文按键路径；需要单独测量复杂公式连续输入的延迟。


## 使用与当前边界

设置 → 排版 → 按键模式可切换默认 / Helix / Vim，写入 Muse 配置目录的 editor.json。顶栏显示模式与待决按键。

当前支持上表基础集和 0 / $ / gg / G；词移动 e、cw 与次数仍为基础实现，不保证与上游逐项一致。Vim 支持次数、行级复制粘贴和基础 Visual。Helix 支持选择后删除、修改、复制、粘贴。尚未实现多光标、宏、命令行、文本对象、命名寄存器和完整 Vim/Helix 兼容。系统 Cmd 快捷键保留。

公式预览已通过 headless 截图核对；macOS 输入法和模态键位的真实交互仍需用户体验验收。全量测试曾暴露既有 headless AI 审批与 paint 回调并发问题，不能将一次重跑通过视作并发安全证明。

Helix / Vim 的 Normal、Select、Visual 使用按字形宽度绘制的块状光标，Insert 保留竖线；选区存在时仍绘制活动端光标。

侧栏拖动越过折叠阈值即收起，无需释放；折叠后编辑区左边缘 hover 显示把手，可右拖重开，同一手势支持反向恢复。

Callout：Note / Tip / Important / Warning / Caution 渲染为按类型配色的圆角卡片，支持自定义标题、段间空行及内部普通引用。源码标题行在进入编辑时展开，保存仍保留原始 Markdown。

表格边缘控件：hover 底边显示新增行条，hover 右边显示新增列条，点击追加到该表格末尾；不改变编辑焦点或滚动位置，选区按源码插入映射，一次撤销恢复。
