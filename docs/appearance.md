# 外观与重点色

设置 → 主题 → 重点色提供红、橙、黄、绿、蓝、紫、粉七个色盘，默认红色。切换立即生效，`settings.json` 的 `accent` 保存预设 ID；旧配置或非法值回退红色。与明暗主题、跟随系统和 AI 开关独立保存。

`native/theme` 统一生成重点色及悬浮、按下、链接、柔和底色、选区与行内代码文字颜色。浅色和深色各自调整明度与饱和度；链接和按钮上的文字检查对比度。界面控件、光标、任务勾选、正文链接、行内代码与普通 NOTE callout 使用这些角色色。错误、警告、代码语法和分类标签保留各自的语义色。

正文采用 Bear 方向的轻量排版：浅色深灰 `#444442`、深色柔白 `#d6d6d2`，Regular 正文、600 标题及粗体，默认行高 1.7。浅色画布为白色；重点色不染正文。链接保留下划线，代码使用中性底色和派生文字色。

不改写 Markdown 内容；引用保留源行、正文软换行、智能排版开关继续沿用原规则。

验证：`sh scripts/go.sh -C native test ./...`；`MUSE_SHOTS=<已存在目录>` 可输出 `nativeui` 的 `TestAccent*` 设置面板和明暗正文截图。
