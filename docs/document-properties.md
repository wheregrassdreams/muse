# 文档标题与属性

标题默认来自文件名（不包含扩展名）。用户修改标题后写入 YAML `title`，覆盖显示标题，文件名保持不变；删除覆盖可恢复文件名标题。标题上的编辑按钮在悬浮时出现。

正文前显示少量高价值属性，标签使用 chip，状态使用状态标记，日期显示自然日期。默认只显示 2–4 项，完整字段从右上角 Info 打开右侧属性面板。布局偏好与 YAML 字段分离，不将 UI 配置写入笔记。

完整面板同时展示用户属性与系统派生信息。文件名、路径、字数等系统信息明确只读并降低对比度；用户在 YAML 中已有的同名概念不会自动被锁定。复杂 YAML 结构在表单中只读，仍能切换源码编辑。无效 YAML 保留原文并显示错误，不强制转换。

属性编辑以最小源码片段更新，保留未修改字段、正文、注释和换行格式，并接入编辑器统一撤销。原始 YAML 仍为权威数据；属性界面是其投影。

默认优先展示 tags、status、date、aliases，摘要最多四项，其余可从“＋N 项”进入面板。置顶、隐藏和上下移动按文档路径保存在 Muse 配置目录的 `document-properties.json`。日期采用 ISO 格式输入，状态常见值映射为自然语言展示；复杂结构和含内部注释的复杂列表请通过 YAML 源码编辑。

标题与摘要随正文滚动，原有顶部渐变模糊保留。2026-11-10 macOS arm64 验收：全量测试、vet、定向 race 与实窗口截图通过；按键 CPU 预算约 5.1ms，小于 8.3ms 闸门。这是该次测试数据，不代表所有文件的延迟上限。
