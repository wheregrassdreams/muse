# 图片显示与预览

笔记内的 Markdown 图片、Wiki 图片嵌入和 HTML `<img>` 共用图片加载器；图片文件通过目录树或打开文件入口显示在编辑区的只读图片页面；页面上的“全局预览”按钮才打开缩放/拖动 overlay，不再默认遮住整个工作区。

全局预览覆盖整个工作区，支持缩放、拖动和平移，以及 Escape 关闭。预览不会替换当前笔记，也不会改变笔记的未保存内容。笔记内图片的预览和源码操作只在鼠标悬浮图片时显示；右下角 L 形把手用于调整显示尺寸，修改可撤销，图片原始文件不被重采样或覆盖。

显示宽度持久化在嵌入语法中，例如 `![说明|320](assets/photo.png)`、`![[assets/photo.png|320]]`，或 HTML `width` 属性。拖动期间预览尺寸，释放后只生成一次可撤销编辑。

本地图片优先相对当前笔记目录解析，其次支持笔记库根目录路径与 Wiki 裸附件名，支持 URL 转义后的文件名和 JPG/JPEG 大小写扩展名。位图通过 MyGo 解码（PNG、JPEG、GIF 首帧、WebP、BMP）；SVG 通过已有 canvas 渲染器转换，最大栅格边长为 4096，避免尺寸异常的 SVG 分配过大像素缓冲。GIF 当前不是动画播放。AVIF 虽可在目录树显示，底层解码器未支持时会显示失败状态。

远程 HTTP/HTTPS 图片在后台获取，超时 15 秒，读取上限 20MiB。笔记和预览同时订阅尚未完成的加载时，都能收到刷新通知。

Vim/Helix 非插入模式使用实心方块光标；方块宽度跟随当前字符的排版宽度，中文比拉丁字符更宽，行末仍保留可见空格宽度。插入模式仍为细线光标。

## 验收（2026-11-10，macOS arm64）

`sh scripts/go.sh -C native test ./...`、`vet ./...` 与 `scripts/build.sh` 通过；图片加载、拖动/取消/撤销、引用式图片、原图字节不变和 Vim 光标的相关 race 测试通过。独立测试窗口确认笔记内 PNG 显示，以及全局预览覆盖侧栏、工具栏和编辑区。按键预算实测约 4.8ms CPU（8.3ms 闸门）；这不是所有文档和所有设备的上限保证。

2026-11-11 回归修正：图片文件默认进入编辑区，显式预览按钮才打开 overlay；JPG/JPEG 使用真实编码文件覆盖文档相对路径、库根路径与裸附件名。保留原笔记未保存草稿，关闭全局预览回到图片页面，前后导航恢复对应页面。
